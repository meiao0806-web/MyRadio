## 三、为什么 m4a 不能从中间起播

实测三种 m4a（喜马 audiobook / 喜马 audiofree / 蜻蜓）的 `mdat` 都是**裸 AAC 块**：

```
三国演义   mdat 中段首字节 78 38 76 4d ...   无 0xFFF 同步字
水浒传     mdat 中段首字节 61 6b 17 50 ...   无 0xFFF 同步字
原来是这样  mdat 中段首字节 b0 80 27 32 ...   无 0xFFF 同步字
```

块边界只存在于文件头 `moov` 的 `stsz` 表里，所以从任意字节开始解码 = 找不到帧边界 = 没声音。

**能做的正确路径**（已用真实文件验证过算法）：

```
帧号   = 秒 × timescale ÷ 1024
字节位 = mdat 负载起点 + Σ stsz[0 .. 帧号-1]     ← 累加，不是估算
```

`timescale`（44100 / 22050）和 `stsz` 都在文件头前 64–120KB 内，取一次 Range 就够。
固件仍缺一个「取文件头 + 累加 stsz」的小模块（约 200 行）。
